1. **Casus** (1 min): Library Management System, twee rollen.
2. **Wat wilde ik leren** (2 min): jouw eigen leerdoelen (bijv. JWT, rollen, testen, UML).
3. **Hoe toon ik dat** (3 min): ontwerp (diagrammen) -> code die daarbij aansluit -> tests (piramide) -> reflectie.
4. **Demo** (3 min): login als student, item lenen, terugbrengen; login als librarian, item beheren, alle leningen.
5. **Vragen**: bedenk zelf 1-2 vragen voor medestudenten (Interactief).

Zorg dat je kunt uitleggen: hoe werkt het JWT, waar wordt de rol gecontroleerd, waarom staat de logica van
`borrow()` in het domein, en waar zit jouw testpiramide.
